# AION 開発計画書

## 1. プロジェクト概要

**プロジェクト名**: AION（AI-Oriented News aggregator）  
**目的**: AI分野のビジネス・開発技術・研究論文に関する情報収集〜レポート生成〜外部ツール連携を自動化するMVPの構築  
**ベンチマーク**: 小川さんのHARO（参考記事）

---

## 2. MVP定義（最小限の成果物）

MVPとして達成すべき機能：

| 機能 | 説明 | 優先度 |
|------|------|--------|
| RSS取得 | 複数情報源からRSSフィードを取得・パース | 必須 |
| 記事フィルタリング | タイトル・日付ベースで当日分を抽出 | 必須 |
| LLM要約生成 | 各記事の要約 + Why it matters を生成 | 必須 |
| Markdownレポート出力 | 構造化されたデイリーレポートを生成 | 必須 |
| MCP連携（Notion/Docbase） | 生成レポートを外部ツールに書き出し | 必須 |
| CLI実行 | コマンドラインから一連のフローを実行 | 必須 |

**スコープ外（MVP後の拡張）**:
- 定期バッチ実行（cron等）
- Web UI
- 重要度スコアリング
- Slack通知

---

## 3. 技術スタック

| レイヤー | 技術 | 理由 |
|----------|------|------|
| 言語 | Python 3.11+ | LLM連携・データ処理に最適 |
| RSS取得 | feedparser | 定番ライブラリ、安定性高い |
| LLM | Claude API (claude-sonnet-5) | 高品質な要約生成 |
| MCP連携 | mcp-python-sdk | Notion/Docbase連携 |
| 設定管理 | YAML + pydantic | 型安全な設定管理 |
| CLI | typer | モダンなCLIフレームワーク |

## 8. 成果物

MVP完了時に得られる成果物：

1. **実行可能なCLIツール**
   ```bash
   python -m aion collect    # RSS収集
   python -m aion summarize  # 要約生成
   python -m aion report     # レポート出力
   python -m aion publish    # MCP書き出し
   python -m aion run        # 全工程実行
   ```

2. **デイリーレポート（Markdown）**
   - カテゴリ別に整理された記事一覧
   - 各記事の要約 + Why it matters
   - 日付・ソース情報付き

3. **外部ツール連携**
   - Notionへのページ作成
   - （オプション）Docbaseへの投稿

## 9. リスクと対策

| リスク | 影響 | 対策 |
|--------|------|------|
| RSSフィードの形式差異 | パース失敗 | フィード別の正規化処理 |
| Claude APIレート制限 | 処理停止 | バッチ処理 + リトライ |
| MCP連携の複雑さ | 工数超過 | Notion単独に絞る |
| 記事量が多すぎる | トークン超過 | 件数制限 + 重要度フィルタ |
